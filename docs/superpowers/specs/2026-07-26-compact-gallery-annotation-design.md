# 紧凑型图库与标注工作台设计

## 1. 目标

重新组织图库和标注页面，让图片与编辑内容占据主要空间，并保留现有图库选择、批量操作、元数据查看、图库到标注的交接和返回能力。

本轮设计采用已确认的 A「紧凑工作台」方向。

## 2. 固定规则

- 吉祥物只出现在仪表盘，不出现在图库、标注及其空状态、加载状态和错误状态。
- 图库和标注不再使用独立大标题区。
- 顶部页面操作压缩为约 44 像素的单行工具栏。
- 重排只改变信息层级与视觉密度，不删减已有业务能力。
- 图库与标注保持分开的一级页面，通过明确的“送去标注”和“返回图库原位置”联动。

## 3. 图库布局

### 3.1 顶部工具栏

顶部工具栏从左到右包含：

1. 当前页面或来源名称。
2. 当前结果数量。
3. 搜索框。
4. 标注状态筛选、排序和缩略图尺寸。
5. 同步图库与添加文件夹。

工具栏保持单行；窗口不足时优先缩短搜索框和隐藏次要文字，不增加第二行标题。

### 3.2 主工作区

- 左栏：图库来源、未标注入口、数据集和文件夹，保持窄栏并允许独立滚动。
- 中栏：图片网格，占据剩余空间；图片名称、标注状态以弱化信息显示，不和缩略图争抢注意力。
- 右栏：默认不占空间；选择一张图片后显示简洁详情，多选时仍以底部批量操作为主。
- 底部操作条：只在多选时出现，提供送去标注、加入数据集、复制或移动等现有操作。

双击图片继续打开沉浸式元数据查看器。查看器内保留上一张、下一张、复制、保存标签和送去标注。

### 3.3 页面状态

- 加载：网格内使用低干扰骨架或文字状态。
- 空图库：仅显示简洁说明和“添加文件夹”按钮，不显示吉祥物。
- 无筛选结果：显示清除筛选操作。
- 扫描或文件操作失败：在工具栏附近显示可关闭提示，不挤占图片区域。

## 4. 标注布局

### 4.1 顶部工具栏

顶部工具栏包含：

1. 当前阶段与完成数量。
2. 当前模型。
3. 返回图库原位置。
4. 开始、停止或继续自动标注。

没有来自图库的返回上下文时，不显示返回按钮。

### 4.2 三栏工作区

- 左栏：可折叠任务队列，默认窄栏；显示文件名和完成、待处理、失败状态，底部提供添加图片。
- 中栏：当前图片预览，占据最大空间；上方只显示文件名、尺寸和上一张/下一张。
- 右栏：标签编辑区；包含识别标签、标签文本、常用编辑动作和“保存并下一张”。
- 底部状态条：自动标注运行时显示进度、成功和失败数量；空闲时保持纤细；只有错误发生时展开错误详情。

空队列和图片读取失败都使用文字与操作按钮表达，不显示吉祥物。

## 5. 页面联动与数据流

1. 用户在图库单选或多选图片。
2. 图库创建包含图片路径和返回上下文的交接数据。
3. 标注页接收交接数据并创建或追加任务队列。
4. 自动识别或人工编辑后，保存动作同时写入图库数据库和同名 `.txt` 文件。
5. 用户返回图库时恢复原来源、搜索、筛选、排序和滚动位置。

页面刷新后，未完成标注队列继续从本地持久化状态恢复；已中断的运行中任务转为可重试状态。

## 6. 组件边界

- `Gallery.vue`：负责页面状态、图库与标注交接、对话框和元数据查看器编排。
- `GalleryToolbar.vue`：负责紧凑顶部工具栏，不持有业务数据。
- `GallerySidebar.vue`：负责来源与数据集导航。
- `GalleryGrid.vue`：负责图片呈现、选择与双击事件。
- `GalleryInspector.vue`：负责单张图片详情，按选择状态挂载。
- `GallerySelectionBar.vue`：负责多选操作，仅在多选时挂载。
- `Tagger.vue`：负责任务阶段与三栏编排。
- `TagQueue.vue`：负责任务选择和状态显示，并支持折叠。
- `TagEditor.vue`：负责标签编辑与保存动作。
- `TagRunProgress.vue`：负责纤细进度与按需展开的错误详情。

业务状态继续由 gallery 和 tagger store 管理，组件只发出用户意图，避免视觉重排破坏保存和队列逻辑。

## 7. 错误处理

- 保存数据库成功但 `.txt` 失败时，明确提示“图库已保存、文本文件未写入”，并允许重试。
- 保存请求异常时必须结束保存中状态，按钮恢复可用。
- 自动标注请求异常时必须结束运行中状态，将当前任务标记为失败并允许重试。
- 图片文件被移动或删除时，队列保留任务并提示重新定位或移除，不让页面崩溃。
- 模型目录未配置时回退到默认目录，不发生递归调用。

## 8. 验收标准

- 图库和标注首屏不再出现独立大标题区。
- 图库和标注页面及其所有状态不渲染 `Mascot`；仪表盘仍保留吉祥物。
- 在 1366×768 窗口中，顶部工具栏保持单行，图片区域比当前版本更高。
- 图库单选、多选、范围选择、双击元数据、筛选和批量操作可用。
- 图库送去标注后队列正确建立；保存后数据库和 `.txt` 状态正确反馈；可以返回图库原位置。
- 标注队列折叠、上一张/下一张、自动标注、停止、重试和保存并下一张可用。
- 保存与推理异常不会让界面永久停留在运行中状态。
- 单元测试、类型检查、IPC 契约检查和生产构建通过。
- 在实际 Electron 窗口中完成图库和标注关键路径的视觉检查。
