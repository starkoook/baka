# 仪表盘舱体风格改版设计

## 目标

恢复旧版仪表盘的二次元工具站气质和小人陪伴感，同时保留新版已经打通的图库、反推、训练、任务状态与系统监控入口。

## 已确认方向

- 删除首页的三步流程展示，不再使用 `01 / 02 / 03` 新手教程式结构。
- 删除大幅宣传标题、宣传文案和顶部三项数字统计。
- 顶部改为紧凑的 `Baka TOOLS` 工作舱标题，只显示工作舱就绪状态。
- 使用旧版 HUD、玻璃舱体、粉色边框和像素装饰语言。
- 小人恢复为首页右侧视觉核心，并保留走动、休息、鼠标视线跟随、点击爱心和对话气泡。
- 左侧放置图库与标注、提示词反推、训练中心三个真实可用模块。
- 小人舱底部提供“继续工作”，根据当前任务、数据集和图库状态跳转。
- 底部仅保留当前任务和系统状态，不堆叠无用统计或禁用按钮。

## 页面结构

1. 紧凑标题栏：产品名称、工作舱状态。
2. 主区域左侧：三个功能模块，每个模块包含名称、用途、当前状态和入口。
3. 主区域右侧：互动小人、对话气泡、全息底座和继续工作入口。
4. 底部左侧：当前标注、安装或训练任务状态。
5. 底部右侧：CPU、GPU、内存的简洁实时状态。

## 状态与跳转

- 有正在运行的训练任务时，“继续工作”进入任务运行页。
- 有数据集但没有运行任务时，进入训练中心。
- 尚未准备数据时，进入图库与标注。
- 模块状态只使用现有图库、数据集、训练任务和系统监控数据，不新增持久化格式。
- 关闭小人显示设置时，主区域自动调整为单列或扩展模块区域，不留下空白舱位。

## 视觉与适配

- 大窗口采用左功能、右小人的双列布局。
- 窄窗口改为上下排列，小人仍然可见。
- 动画遵守系统的减少动态效果设置，小人保持静止展示。
- 不修改全局主题变量，不影响图库、反推和训练页面。

## 验收标准

- 首页不再出现三步流程、宣传式巨型标题和三项摘要统计。
- 小人在默认设置下首屏可见，互动效果可用。
- 图库、反推、训练和继续工作入口均可点击并跳转正确。
- 1280×720 下无横向溢出，主要内容不被状态栏遮挡。
- 关闭小人后页面不出现明显空洞。
- 类型检查、仪表盘测试和正式构建通过。
