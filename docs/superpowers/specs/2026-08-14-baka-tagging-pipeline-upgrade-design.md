# 图库标注流水线升级设计

## 目标

把 Baka TOOLS 的标注功能从“本地 WD14 输出少量标签”，升级为接近 BDTM 的完整标注流水线：

1. 一个统一的打标入口。
2. 生成时可选择输出标签、自然语言，或两者都要。
3. 本地 ONNX、云端 LLM、组合模式可切换。
4. 打标结果先预览，再安全写入。
5. 支持模型目录、提示词模板、并发、后处理、批量进度和取消。

## 范围

本轮实现：

- 统一打标窗口和设置面板。
- 输出模式：标签、自然语言、标签 + 自然语言。
- 打标来源：本地 ONNX、LLM、组合、自然语言。
- 多套 LLM API 配置与多 Key 轮换。
- 提示词模板库。
- 本地 ONNX 模型目录与下载。
- 标签后处理、清洗、排序、去重、前后缀、下划线转换。
- 写入模式：全部替换、追加、跳过已有、只处理空标签。
- 先本地粗标，再 LLM 精修的自动流水线。
- 角色标签审计作为第二阶段实现。

本轮不做：

- 在线自动更新模型目录。
- 云端标签翻译服务。
- 完整 Danbooru Wiki。

## 统一入口设计

### 一个窗口

新窗口或升级后的标注页只提供一个“开始生成”入口，内部有：

- 来源：本地、LLM、组合、自然语言。
- 输出模式：标签、自然语言、标签 + 自然语言。
- 处理范围：选中图片、当前文件夹、全部图片。
- 模型、提示词模板、并发、阈值、写入模式。

### 输出模式规则

#### 标签模式

模型只输出逗号分隔的标签。

示例：

```text
1girl, long hair, blue eyes, school uniform, standing
```

#### 自然语言模式

模型输出一段完整描述。

示例：

```text
一个蓝色长发的女孩，穿着校服，站在户外，看向镜头。
```

#### 标签 + 自然语言模式

输出同时包含标签和自然语言，使用结构标记分隔。

```text
<TAGS>
1girl, long hair, blue eyes, school uniform, standing
</TAGS>
<NL>
一个蓝色长发的女孩，穿着校服，站在户外，看向镜头。
</NL>
```

## 组合模式

组合模式流程：

```text
图片没有标签
  -> 本地 ONNX 粗标
  -> 得到基础标签
  -> 把图片和基础标签一起交给 LLM
  -> LLM 根据选择的输出模式生成结果
  -> 后处理
  -> 预览
  -> 安全写入
```

这解决用户遇到的两个问题：

1. 本地只出简单标签。
2. 直接问网页大模型会输出一大串非结构化文本。

## 提示词模板

内置：

- Danbooru Tags
- Natural Language
- Tags + Natural Language
- Natural Language 2

允许用户自定义模板并导入/导出 JSON。

## 后处理规则

1. 去除 `&lt;think&gt;` 内容。
2. 去除 Markdown 代码块。
3. 按逗号、换行、分号拆标签。
4. 去空格、去引号、去反斜杠。
5. 去重。
6. 非法标签过滤。
7. 可选按置信度或字母排序。
8. 应用前后缀。
9. 下划线转空格或保留。
10. 标签 + 自然语言结构解析。

## 写入模式

### 全部替换

清空原标签，写入新结果。

### 追加

保留原标签，追加新标签。

### 跳过已有

如果图片已有标签，则不处理。

### 只处理空标签

只对没有标签的图片生成。

## 角色标签审计

第二阶段实现：

- 文本初筛。
- 视觉复核。
- 逐条决定保留、删除、替换、不确定。
- 父子标签冲突检测。
- 多角色支持。
- 事务化写入。

## 错误处理

- LLM 请求失败时单张标记失败，不中断整批。
- 本地 ONNX 失败时可降级 CPU。
- 所有写入使用 `safe-file.js`。
- 批量操作使用回收站和失败清单。

## 测试

需要覆盖：

- 组合模式编排。

## 验收标准

1. 一个统一入口可以选择输出标签、自然语言、两者都要。
2. 本地、LLM、组合模式都能运行。
3. 支持多 API 配置和多 Key。
4. 支持 WD14、PixAI、CL Tagger 模型目录。
5. 提示词模板可切换。
6. 写入前有预览。
7. 批量处理有进度和取消。
8. 失败不破坏原文件。
9. 相关测试和类型检查通过。
