# 工作台升级设计：ComfyUI 式流程管理 + LibTV 手感（双引擎）

- 日期：2026-08-12
- 状态：已与用户逐节确认（方向 / 左栏 / 动效 / 双引擎 / 资产面板）
- 目标版本：baka-tools 0.1.0（工作台 Workbench.vue）

## 背景与目标

用户希望工作台成为"ComfyUI + LibTV 的结合版"：保留 LibTV 的易用手感（节点内编辑、内嵌生成器），补上 ComfyUI 的流程管理能力（自动保存、最近项目、运行进度、结果资产、引擎接入）。判断标准是实用、能跑通、有实际作用，不与主流工具攀比。

概念分层（给用户的大白话）：

- 模型 = 发动机（SD / SDXL / FLUX 等模型文件，几 GB）
- 引擎软件 = 驾驶舱（ComfyUI / WebUI，本机软件，负责加载模型跑图）
- 云平台 = 租车行（NovelAI / LibTV / 哩布，服务器跑，付费使用）

我们的工具箱负责"方向盘"：画布、节点、流程、结果都在工具箱里，AI 执行要么走云端 API（租车），要么连本机引擎（开自己家的车）。

## 范围

本次做：

1. 工作台左栏 UI 重构（ComfyUI 式图标栏 + 动态按钮区 + 动效）
2. 流程管理：自动保存、最近项目列表、运行进度条 + 取消
3. 结果资产面板：生成结果自动收集、预览、保存、拖回画布
4. 双引擎：云端 API（现有）+ 本地引擎（ComfyUI / WebUI 检测、填地址、填路径启动）

范围外（以后再做）：一键安装引擎（第三档）、模板/片段复用、批量运行、视频生成与剪辑、NovelAI 等更多云端平台接入。

## 界面设计（已批准）

### 左栏图标栏

- 窄条（约 48px），六个图标：项目 / 节点库 / 队列（运行进度）/ 结果（资产）/ 引擎 / 设置
- 悬停：图标浮起 + 高亮 + 显示名字（tooltip）
- 点开：面板从左侧弹性滑出（约 0.2s），点画布空白或再点图标收起
- 动态按钮区：
  - 进入画布时，基础按钮依次滑入：添加节点、保存、打开、撤销、重做、视图（放大/缩小/适配全部）、运行
  - 选中节点时，自动切换为该节点的操作组：运行此节点、复制、粘贴、删除、保存内容、生成器开/关
- 底部常驻：引擎状态（云端/本地 + 连接状态）、设置
- 画布顶部只保留运行按钮，其余功能收进左栏

### 动效规范

- 面板滑出/收起：200ms ease-out + 轻微回弹
- 节点添加/删除：放大淡入 / 缩小淡出（150ms）
- 连线：从起点生长到终点；运行中线条有流动光效
- 节点状态：运行中徽章脉冲、完成 ✓ 弹跳、出错轻抖 + 红边
- 进度条平滑推进；toast 淡入淡出
- 设置提供"减弱动画"开关；系统"减少动画"偏好（prefers-reduced-motion）同样生效

## 流程管理设计

### 自动保存

- 触发：增删节点、连线、参数、位置、生成结果变化后，防抖 1.5s 自动保存
- 运行期间暂停自动保存，运行结束后补存一次
- 位置：数据目录（getDataRoot）下 `workflows/autosave.bakaflow.json`
- 启动：打开工作台自动加载上次自动保存的画布（无文件则空白画布）
- 手动保存仍为正式保存（Ctrl+S / 保存按钮 / 另存为），保存路径写入最近项目 index
- 自动保存成功：右下角 toast"已自动保存"；失败：toast 提示，不打断编辑
- 打开任意项目前自动 snapshot，Ctrl+Z 可回退（沿用现有机制）

### 最近项目

- index 文件：`workflows/recent.json`，记录 `[{ path, name, updatedAt, thumbnail? }]`，上限 20 条
- 左栏"项目"面板：列表显示最近项目（名称 + 修改时间），点击打开；可删除列表项（不删文件）
- 提供"新建画布"按钮；当前项目名显示在画布顶部
- 打开失败：toast 报错，不清空当前画布

### 运行进度条 + 取消

- 整组运行时底部进度条：`正在跑 第 x/y 个节点：节点名`，节点状态实时更新（沿用现有徽章）
- "取消运行"按钮：中止当前执行链，已跑完节点保留结果，取消的节点标记为未运行
- 运行中禁止重复启动（简单互斥；多任务队列留后续）

## 结果资产面板

- 每次节点运行成功，结果自动入资产：图片（data URL 持久化为本地文件）、文本（内容/文件）、视频（路径）
- 记录：`assets/index.json` + 文件目录 `assets/files/`，含来源节点、时间、类型、参数摘要
- 面板：按时间倒序，缩略图列表；点开大图预览 + 信息；一键保存到任意位置；删除单条；清空
- 拖回画布：拖到画布生成对应类型节点（图片/文本/视频）
- 容量：默认保留最近 200 条，可手动清理
- 资产独立于 `.bakaflow.json` 保存，但工作流文件可引用资产路径

## 双引擎设计

### 概念

- 引擎抽象层：节点只描述能力（文生图/图生图/高清/扩图/文本等），执行由"引擎适配器"翻译
- 引擎类型：`cloud`（现有 API 凭据库）/ `comfy`（本地 ComfyUI）/ `webui`（本地 WebUI/Forge）
- 节点运行：优先用节点内选择的引擎；未选则用全局默认引擎；无可用引擎时明确提示

### 云端（现有）

- 复用 `llm:chat` / `llm:image` / 凭据库，行为不变

### 本地 ComfyUI

- 检测：`http://127.0.0.1:8188`（ComfyUI 默认端口）
- 模型列表：`GET /object_info` 读取 checkpoints / loras / samplers
- 运行：翻译器构造最小 workflow JSON → `POST /prompt` → 轮询 `/history` → `/view` 取图回填节点
- 用户不接触 ComfyUI 界面

### 本地 WebUI（A1111 / Forge）

- 检测：`http://127.0.0.1:7860`
- 模型列表：`GET /sdapi/v1/sd-models`、`GET /sdapi/v1/samplers`
- 运行：`POST /sdapi/v1/txt2img` 或 `img2img`；高清/扩图用 img2img 参数映射

### 连接方式（三选一）

1. 自动检测（端口探测）
2. 手动填地址（改端口 / 局域网 / 其他机器）
3. 填安装路径自动启动：识别目录（ComfyUI 有 `main.py` + `python_embeded/python.exe`；WebUI 有 `webui.bat`），后台启动并等待端口就绪，成功后显示"已连接"

引擎面板显示状态：未检测 / 启动中 / 已连接（类型 + 地址 + 模型数）/ 失败原因。

### 翻译器范围（第一批）

- 文生图、图生图（含参考图）、高清放大、扩图、重绘 → ComfyUI / WebUI 对应请求
- 文本生成 / 打标暂仍走云端（本地 LLM 后续）

## 错误处理与状态

- 本地引擎未开/未找到：明确提示 + 三种连接方式引导
- API Key 未配置 / 余额不足 / 网络错误：沿用现有报错，直接显示原因
- 自动保存失败：toast，不打断编辑
- 打开失败：toast，不清空当前画布
- 取消运行：状态复位正确，已跑完节点保留结果
- 资产写入失败：提示，不影响画布

## 分步实现

1. 后端：自动保存 + 最近项目 index + 资产 index/文件（electron IPC + main handlers）
2. 左栏 UI 重构 + 动效（Workbench.vue）
3. 运行进度条 + 取消
4. 结果资产面板（收集 / 预览 / 保存 / 拖回）
5. 本地引擎：检测 + 填地址 + 模型列表 + ComfyUI 翻译器（文生图/图生图）
6. WebUI 翻译器 + 填路径自动启动
7. 验证：typecheck + 全部测试 + build + 手动验证

## 测试与验证

- `npm run typecheck`
- `npm test -- --run`（现有全部测试保持通过）
- `npm run build`
- 手动验证清单：
  - 自动保存：改画布停手 1.5s 后 toast；重启自动恢复
  - 最近项目：保存/打开后出现在列表；点击打开；删除列表项
  - 进度条：整组运行显示"第 x/y 个节点"；取消运行生效
  - 资产：生成结果自动入库；预览/保存/删除/清空；拖回画布生成节点
  - 本地引擎：用用户电脑上的秋叶启动器（ComfyUI）验证检测 + 文生图/图生图翻译器
  - 动效：面板滑出、节点增删、连线流动；"减弱动画"开关生效

## 关键约束

- 画布交互（左键平移 / 空格+左键框选）不变
- 新节点内容区保持底部圆角（既有约定）
- 密钥只存本地凭据库，不写进画布文件
- 自动保存 / 资产文件放数据目录，不污染仓库
- 动效克制：所有动画 ≤250ms，默认开启，可关闭
