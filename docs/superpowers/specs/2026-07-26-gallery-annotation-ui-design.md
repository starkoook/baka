# 图库与标注双工作台 UI 设计

日期：2026-07-26

状态：用户已确认页面方向、图库布局、标注布局和元数据查看器

## 1. 目标

把当前混在同一页面中的图库浏览、临时标注队列、批量标注和数据集操作拆成两个职责清楚的工作台：

- **图库**负责导入、浏览、筛选、挑选、整理图片和查看元数据。
- **标注**负责接收图片队列、运行自动标注、逐张校对和保存标签。
- 两个页面保留明确联动，但不共享混乱的页面状态，也不要求复制图片。

完成后，用户应能自然完成以下流程：

1. 在图库选择一个文件夹并浏览图片。
2. 单击选择，双击查看图片和元数据。
3. 选择多张图片后点击“送去标注”。
4. 在标注页选择模型并运行自动标注。
5. 逐张校对、保存标签，并返回图库原位置。

## 2. 已确认方向

采用“**双工作台**”方案，不采用图库与标注合并页，也不采用强制步骤向导。

| 页面 | 核心职责 | 不承担的职责 |
|---|---|---|
| 图库 | 文件夹、图片网格、搜索筛选、元数据、文件整理、建立标注任务 | 模型参数配置、批量推理过程、长时间标签校对 |
| 标注 | 任务队列、模型选择、自动标注、标签校对、进度与失败重试 | 文件夹树、图库扫描、复杂文件管理 |

页面路由调整为：

- `/gallery`：图库
- `/tagger`：标注

顶部导航将“图库 & 标注”拆为“图库”和“标注”两个入口。

## 3. 图库页面

### 3.1 页面结构

图库使用“来源栏 + 图片网格 + 按需详情”的结构：

- 顶部：页面名称、当前文件夹图片数量、添加文件夹、同步。
- 工具栏：搜索、标签状态、排序方式、网格/列表视图。
- 左侧：图片文件夹、最近加入、未标注等快捷筛选；数据集作为次级分组保留在图库侧，不与标注页混合。
- 中间：尽可能大的图片网格。
- 右侧：仅在单选图片时出现详情栏，普通浏览和批量选择时不占空间。
- 底部：仅在批量选择时出现操作栏。

### 3.2 选择行为

- 单击图片：选择当前图片。
- `Ctrl`/`Shift`：追加选择或连续选择。
- 点击缩略图勾选区：切换批量选择，不打开查看器。
- 双击图片：打开沉浸式元数据查看器。
- `Esc`：清除选择；查看器打开时优先关闭查看器。

### 3.3 批量操作栏

批量操作集中在底部，不再使用右侧多张功能卡片。操作顺序固定为：

1. 送去标注。
2. 加入数据集。
3. 复制或移动。
4. 取消选择。

删除、移动原图等有风险的操作必须二次确认。占位的“更多功能开发中”卡片删除，不在界面中展示尚未实现的功能。

### 3.4 数据集入口

现有数据集能力保留在图库的次级区域：

- 左侧栏显示数据集分组和图片数量。
- 选择数据集后，中间仍使用同一图片网格。
- 可以从批量操作栏把图片加入已有数据集或新建数据集。
- 数据集中的 caption 可以查看；需要集中编辑时发送到标注页。
- 数据集导出保留在数据集视图工具栏，不占普通图库工具栏。

## 4. 沉浸式元数据查看器

### 4.1 采用方案

采用“A 沉浸查看器”，不再使用当前把标签、模型卡片、生成参数、提示词全部堆进窄侧栏的方式。

### 4.2 布局

- 顶部：文件名、尺寸、文件大小、打开文件位置、送去标注、关闭。
- 左侧约三分之二：大图预览和前后切换。
- 右侧约三分之一：概览、生成信息、标签三个页签。
- 底部：完整路径和快捷键提示。

默认打开“概览”，让图片始终是视觉主体。

### 4.3 三个页签

**概览**显示：

- 模型名称和生成器。
- 尺寸、Steps、CFG、Seed、采样器和生成时间。
- 使用的 LoRA 与权重。
- 复制全部元数据。

**生成信息**显示：

- 正向提示词和单独复制按钮。
- 反向提示词和单独复制按钮。
- VAE、Clip Skip、Scheduler、生成软件等扩展字段。
- 缺失字段不显示空卡片。

**标签**显示：

- 当前图片已有标签。
- 搜索、添加、删除和保存。
- “送去标注”仍是独立动作，不把元数据查看器变成完整标注页。

### 4.4 交互

- 左右方向键：上一张/下一张。
- `Esc`：关闭。
- 双击大图或使用缩放按钮：适配窗口/查看原始尺寸。
- 切换图片时保持当前页签。
- 没有 Stable Diffusion 元数据时只显示基础文件信息和已有标签，不显示大片空白区域。

## 5. 标注页面

### 5.1 页面结构

标注页采用“任务队列 + 大图 + 标签编辑器”三栏结构：

- 顶部：任务来源、标注方式、模型设置和当前主操作。
- 左侧：任务队列、每张图片状态和继续添加图片。
- 中间：当前图片大图、上一张/下一张、批量进度。
- 右侧：标签搜索、添加、删除、分组校对和保存操作。
- 底部：本次使用的模型、阈值和设备摘要。

### 5.2 三种任务状态

**准备标注**：

- 展示队列数量和来源。
- 选择本地 WD14、云端视觉模型或两者结合。
- 常用设置直接显示，高级设置从“模型设置”打开。

**自动标注中**：

- 进度显示在大图下方，不覆盖整个页面。
- 显示完成数、总数、当前文件和运行设备。
- 停止操作进入明确的“正在停止”状态，不提前显示已取消。

**人工校对**：

- 自动进入第一张未校对图片。
- 标签按角色与主体、表情与动作、服装与画面等类别分组。
- 主操作为“保存并下一张”。
- 支持把当前修改应用到所选图片，但必须显示影响数量。

## 6. 两个页面的联动

### 6.1 图库到标注

图库点击“送去标注”时传递：

- 图片数据库编号。
- 图片绝对路径。
- 当前顺序。
- 来源文件夹或数据集编号。
- 图库筛选和滚动定位信息。

不复制图片，也不建立第二套图库记录。

### 6.2 标注结果回写

- 每张图片校对保存后立即写入图库数据库。
- 同步写入图片同名 `.txt` caption。
- 数据库与文件均成功后才显示“已保存”。
- 一方写入失败时显示“部分保存”，保留待重试内容，不伪装成功。

### 6.3 返回图库

点击“返回图库原位置”后：

- 回到原文件夹或数据集。
- 恢复搜索和筛选条件。
- 定位并高亮当前图片。
- 批量任务完成时可以恢复原选择，也可以只定位最后处理图片；默认恢复原选择。

## 7. 状态保存与错误恢复

- 标注任务队列、当前图片、已完成编号、失败编号和本次模型配置需要持久保存。
- 中途关闭应用后可以继续未完成任务。
- 单张失败不终止整批任务；失败图片进入可重试列表。
- 模型缺失、文件被移动或标签写入失败时，说明发生了什么、受影响图片和下一步操作。
- 图库扫描失败时保留现有图片，不清空旧结果。
- 文件移动后更新图库记录和标注队列引用，避免队列指向旧路径。

## 8. 视觉设计

- 延续现有深色底、粉橙强调色和圆润控件。
- 减少大面积辉光、扫光和持续运动效果，让图片本身更突出。
- 卡片只用于真正独立的内容，不给每个参数套一层卡片。
- 主按钮每个操作区最多一个；次要动作降级为普通按钮或文字按钮。
- 图标统一使用线性图标，emoji 只用于小人台词或轻量提示。
- 小人用于空图库、扫描完成、任务完成和错误恢复引导，不常驻遮挡图片。
- 小窗口时按“来源栏 → 图片 → 详情/编辑”的顺序纵向重排；重要操作不隐藏在横向滚动区域。

## 9. 组件边界

现有 `TaggerV2.vue` 同时承担图库、临时工作区、数据集和标注流程，实施时拆分职责：

- `Gallery.vue`：图库页面编排。
- `Tagger.vue`：标注页面编排。
- `GalleryGrid.vue`：图片网格和选择，不负责标注任务。
- `MetadataViewer.vue`：沉浸式查看器和元数据页签。
- `GallerySelectionBar.vue`：批量图库操作。
- `TagQueue.vue`：标注队列和单图状态。
- `TagEditor.vue`：当前图片标签编辑。
- `TagRunProgress.vue`：批量标注进度和停止状态。
- `gallery` store：文件夹、图片、筛选、选择和图库定位。
- `tagger` store：标注队列、模型配置、任务进度、失败重试和恢复。

组件通过明确的 props、事件和 store 动作通信，不通过全局临时变量传递文件夹路径。

## 10. 验证标准

实现完成后至少验证：

1. 顶部导航可分别进入图库和标注。
2. 单击只选择图片，双击只打开元数据查看器。
3. 查看器三个页签、前后切换和快捷键正常。
4. 无元数据图片不会出现空参数卡片。
5. 批量选择栏只在选择图片后出现。
6. “送去标注”保持图片顺序和来源定位。
7. 标注进度不遮挡页面，停止状态与真实任务一致。
8. 标签保存同时更新数据库和 `.txt`，失败状态准确。
9. 中途退出后可以恢复标注任务。
10. 返回图库后恢复原文件夹、筛选和图片位置。
11. 窄窗口下所有主要操作仍可访问且不重叠。

## 11. 本轮不做

- 不更换 WD14 推理核心或云端视觉接口。
- 不增加视频、音频或非图片资产管理。
- 不重写 LoRA 训练页面。
- 不在图库中嵌入完整标注编辑器。
- 不实现与本设计无关的新图像处理工具。
