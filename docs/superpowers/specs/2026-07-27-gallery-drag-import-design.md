# 图库拖拽读取恢复设计

## 目标

恢复紧凑版图库改版时遗漏的拖拽能力，让用户把图片或文件夹直接拖到图库主体区域即可读取，不改变现有图库布局、筛选、选择、元数据窗口和标注联动。

## 交互行为

- 文件进入图库区域时，显示覆盖图库内容区的虚线提示层，明确提示“松开以读取图片”。
- 拖出图库或完成处理后，提示层立即消失，不遮挡侧栏、工具栏和弹窗。
- 拖入一张受支持的图片时，直接读取该图片并打开现有元数据查看器；该临时查看不会自动扩大图库目录范围。
- 拖入多张图片时，只导入这些图片。导入完成后刷新当前图库，并给出成功、跳过和失败数量。
- 拖入文件夹时，将文件夹作为图库来源加入并扫描；如果已经存在，则直接重新同步，不重复创建来源。
- 支持 PNG、JPG、JPEG、WEBP、BMP。其他文件忽略，并通过状态提示说明原因。

## 数据与组件边界

- `Gallery.vue` 只负责拖拽状态、输入分类和调用现有元数据窗口。
- 可独立测试的拖拽输入整理函数负责去重、扩展名过滤，以及区分单图、多图和文件夹。
- 主进程负责确认路径类型和导入明确选择的文件，避免前端自行猜测路径或扫描整块磁盘。
- 批量导入沿用图库现有数据库、元数据解析和缩略图流程；重复路径更新现有记录，不生成重复图片。

## 异常处理

- 无法取得系统路径时，提示“无法读取拖入内容”，界面恢复正常。
- 单图元数据读取失败时，不加入临时图片，并显示读取失败原因。
- 批量导入允许部分成功，最终汇总成功、跳过和失败数量。
- 拖入空文件夹或全是不支持的文件时，不修改图库，只显示说明。

## 验收标准

1. 单张图片拖入后打开现有元数据查看器，能显示图片和可读取的生成参数。
2. 多张图片拖入后只导入所选图片，不额外扫描它们所在目录。
3. 文件夹拖入后出现在图库来源中并完成扫描；重复拖入不会新增重复来源。
4. 拖拽提示层只在拖入期间出现，离开、放下或出错后均会关闭。
5. 非图片文件不会被导入，现有图库浏览、双击元数据和送去标注功能继续通过测试。
