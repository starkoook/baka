# 图库中文标签匹配、批量修标签与父子标签设计

## 目标

让 Baka TOOLS 的图库和标注流程支持：

1. 用中文查找英文标签。
2. 批量添加、删除、替换、清理标签。
3. 按标签类别排序和筛选。
4. 使用本地 Danbooru 角色关系表进行父子标签检查与合并。

## 范围

本轮实现：

- 内置中文标签字典和 Danbooru 角色标签关系表。
- 标签搜索同时支持中文和英文。
- 标签结果展示英文标签、中文名、类别。
- 图库多选图片后可打开批量改标签窗口。
- 批量改标签前先预览，确认后才写文件。
- 标签面板支持分类排序和分类筛选。
- 父子标签冲突检测、预览和合并。

本轮不做：

- 自动下载最新 Danbooru 数据。
- 云端标签翻译服务。
- 完整 Danbooru Wiki 浏览器。
- 全量标签数据库。

## 现状

相关代码：

- `electron/ipc/tagger-vocab.js`：现有英文标签搜索。
- `electron/ipc/tagger-v2.js`：`bulkDryRun` / `bulkApply` 目前是空实现。
- `src/stores/tagger.ts`：标注队列和保存逻辑。
- `src/components/tagger/TagEditor.vue`：标签编辑 UI。
- `src/views/Gallery.vue`、`GallerySelectionBar.vue`：图库多选操作。

## 数据文件

新增本地数据目录：

- `resources/tag-data/danbooru-0-zh.csv`：中文名 -> 英文标签。
- `resources/tag-data/danbooru_character_tags.csv`：角色标签父子关系。

数据来自兼容的公开标签数据。应用启动时加载，不在线请求。

## 架构

### 主进程

#### `electron/ipc/tag-catalog.js`

新模块，负责：

- 加载中文标签字典。
- 加载角色父子关系表。
- 建立中文反查索引。
- 查询父标签、子标签、显示名。

#### `electron/ipc/tagger-vocab.js`

扩展：

- 搜索时同时返回英文标签、中文名、类别。
- 支持中文前缀搜索和包含搜索。

#### `electron/ipc/tagger-v2.js`

实现：

- `bulkDryRun`：根据图片 ID 和操作类型，返回每张图修改前后的标签预览。
- `bulkApply`：确认后批量修改数据库标签和对应 caption 文件。
- `cleanup` 操作：清理重复标签、检测父子冲突、生成合并建议。

### 渲染进程

#### `TagEditor.vue`

- 搜索框支持中文。
- 标签结果按类别上色。
- 增加分类筛选下拉框。

#### `GallerySelectionBar.vue`

- 增加“批量改标签”按钮。

#### 新组件 `BatchTagDialog.vue`

- 选择操作：添加、删除、替换、清理、父子合并。
- 输入标签或规则。
- 展示预览。
- 确认后调用 `bulkApply`。

## 数据流

### 中文搜索

```text
用户输入“蓝色长发”
  -> 渲染进程调用 taggerV2:searchTags
  -> tag-catalog 查中文索引
  -> 返回 blue_hair、long_hair、blue eyes 等
  -> TagEditor 显示英文标签 + 中文名 + 类别
```

### 批量修改

```text
用户选择一批图片
  -> 打开批量改标签窗口
  -> 选择操作和规则
  -> 调用 bulkDryRun
  -> 显示每张图修改前后标签
  -> 用户确认
  -> 调用 bulkApply
  -> 数据库和 caption 文件使用安全写入更新
  -> 返回成功/失败清单
```

### 父子合并

```text
扫描当前范围内的图片标签
  -> 用角色关系表识别父标签和子标签
  -> 统计子标签出现次数
  -> 生成合并建议
  -> 用户预览并选择要合并的项
  -> 批量替换子标签为父标签
```

## 批量操作定义

### 添加

给目标图片添加一个或多个标签，跳过已存在标签。

### 删除

从目标图片删除一个或多个标签。

### 替换

把一个标签或一组标签替换为另一个标签。

### 清理

- 删除重复标签。
- 合并 `1girl` / `2girls` 这类人数冲突，保留人数最多且一致的标签。
- 删除多人图中的 `solo`。

### 父子合并

- 当同一角色家族多个标签同时出现时，按出现次数建议保留父标签。
- 子标签出现次数低于阈值时，建议并入父标签。

## 错误处理

- 批量修改使用 `electron/ipc/safe-file.js` 安全写入 caption。
- 单张图片失败不中断整批。
- 返回失败路径和错误信息。
- 所有路径经过规范化，禁止越界操作。

## 测试

需要覆盖：

- 中文标签反查。
- 中文前缀/包含搜索。
- 批量添加、删除、替换预览。
- 批量应用后数据库和 caption 文件一致。
- 重复标签清理。
- 父子标签冲突检测。
- 父标签合并建议。
- 单张失败时不影响其他图片。

## 验收标准

1. 输入“蓝色长发”能搜到 `blue_hair`、`long_hair` 等标签。
2. 选中 10 张图，批量添加标签时先看到预览。
3. 确认后 10 张图的数据库标签和 `.txt` 文件都被正确更新。
4. 批量替换 A -> B 后，A 不再出现，B 正确出现。
5. 标签面板能按类别筛选和排序。
6. 父子标签合并前有预览，确认后才修改。
7. 相关测试和类型检查通过。
