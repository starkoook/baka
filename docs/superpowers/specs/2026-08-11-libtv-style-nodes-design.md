# LibTV 式素材节点升级设计

- 日期：2026-08-11
- 状态：已与用户逐节确认（界面 / 数据流 / 接口与步骤）
- 目标版本：baka-tools 0.1.0（工作台 Workbench.vue）

## 背景与目标

用户希望工作台做出 LibTV（LiblibAI 无限画布）那种"素材节点内嵌 AI 能力"的体验：

- 图片节点、文本节点内部直接带生成器，不用另拖独立 AI 节点
- 生成结果自动派生新节点，不覆盖原图
- 节点内带工具集（本地工具 + AI 工具）

现有基础：工作台已有开放节点注册（图片/视频/文本/绕线/缩放/保存/AI 打标/LLM 文本）、画布 API 凭据库（任意 OpenAI 兼容服务商 + Gemini）、通用对话接口（`llm:chat`）、单节点运行与整组运行、节点状态（运行中/完成/出错）、保存下载。

## 范围

本次做（方案 3，经用户确认）：

1. 图片节点内嵌生成器，生成器内支持**文生图 / 图生图模式切换**
2. 文本节点内嵌生成器（提示词模板 `{{input}}`）
3. 生成/工具结果**自动派生新节点并连线**（图片类），文本直接写回节点（可撤销）
4. 节点内工具集：本地工具（裁剪/宫格切分/缩放/旋转）+ AI 工具（高清放大/扩图/重绘）
5. 通用生图接口 `llm:image`，按节点所选配置分发

范围外（以后再做）：视频生成/视频工具、更多工具集、多节点批量生成、工作流保存/分享。

## 界面设计（已批准）

### 图片节点

自上而下：

- 标题栏：类型徽标 + 标题 + 全屏/下载按钮
- 图片预览区（节点当前图）
- 内嵌生成器：
  - 模式切换：文生图 / 图生图
  - API 配置下拉（来自凭据库）
  - 模型下拉（默认用配置模型，可拉取模型列表）
  - 提示词输入框
  - 比例预设（1:1 / 16:9 / 9:16 等，按配置能力）
  - 生成按钮 + 状态
- 工具条：裁剪 / 宫格切分 / 缩放 / 旋转（本地，紫色边标记）；高清放大 / 扩图 / 重绘（AI，灰色标记）
- 派生提示：生成后自动派生新节点

### 文本节点

- 正文区（可编辑）
- 内嵌生成器：API 配置 + 模型 + 提示词模板（`{{input}}` 引用正文）+ 生成按钮 + 状态

### 派生节点

- 生成完成：在原节点旁自动创建新图片节点（新 id、偏移位置、装入新图）
- 自动连一条线：原节点 → 新节点，形成链式（可继续生成/编辑）
- 本地工具：直接作用在原节点（可撤销）；AI 生成与 AI 工具：派生新节点
- 宫格切分：一次派生一排新节点
- 图生图模式：以节点当前图（预览区）为参考图；节点无图时提示先加载图片或切到文生图

## 数据流

```
图片节点(参考图+提示词)
  └─ 生成 ─▶ 派生新图片节点 ──(连线)──▶ 继续生成 ─▶ 再派生
文本节点(正文 + {{input}} 模板)
  └─ 生成 ─▶ 结果写回节点正文（Ctrl+Z 可撤销）
```

## API 设计

### 新增 `llm:image`（通用生图）

参数：`{ provider, baseUrl, apiKey, model, prompt, imageBase64?, mimeType?, size?, count? }`

- OpenAI 兼容：`POST {baseUrl}/images/generations`，带参考图时优先尝试该服务支持的编辑/参考方式，不支持则报"该服务不支持图生图"
- Gemini：`generateContent` + 支持生图的模型（如 `gemini-2.5-flash-image`），带参考图时走多模态输入
- 返回：`{ success, images?: string[] /* data URL */, error? }`
- 图片统一压缩/限幅后再上传（复用现有 `resizeBase64` 思路），避免 413

### 复用现有接口

- `llm:chat`：文本生成
- `llm:listModels`：节点内拉取模型列表
- `llm:test`：配置测试
- 凭据库（`llm:listApiConfigs` / `saveApiConfig` / `deleteApiConfig`）：节点选择配置

## 工具集实现

### 本地工具（canvas，不花 API）

- 裁剪：节点内拖选框 → 裁剪
- 宫格切分：2×2 / 3×3 / 5×5，自动派生一排新节点
- 缩放：选目标宽度
- 旋转：90° 步进
- 全部可撤销（进入历史快照）

### AI 工具（依赖生图接口能力）

- 高清放大（2×/4×）、扩图（外扩）、重绘（涂抹区域）
- 通过 `llm:image` 相应能力实现；服务商不支持时明确提示"该服务不支持此工具"
- 结果派生新节点，不覆盖原图

## 错误处理与状态

- 生成/工具执行状态：生成中… → 完成 ✓ / 失败 ! + 原因
- 失败原因直接显示：未选配置、密钥未配置、接口不支持、余额不足、网络错误等
- AI 节点不会在连线时自动调用 API，只在点击生成/运行时调用

## 分步实现

1. 后端 `llm:image` 接口，用现有 Gemini 代理验证文生图/图生图
2. 图片节点内嵌生成器（模式切换 + 配置/模型/提示词/比例 + 生成 → 自动派生连线）
3. 文本节点内嵌生成器（模板 `{{input}}` → 写回正文，可撤销）
4. 本地工具：裁剪 / 宫格切分 / 缩放 / 旋转
5. AI 工具：高清 / 扩图 / 重绘（尽力支持 + 明确报错）
6. 状态/错误/撤销完善；`typecheck` + 全部测试 + `build`；手动验证生成链路与派生

## 测试与验证

- `npm run typecheck`

- `npm run build`
- 手动验证：文生图、图生图、文本生成、派生连线、本地工具、AI 工具报错提示、撤销

## 关键约束

- 密钥只存本地凭据库，不写进画布文件
- 画布交互（左键平移 / 空格框选）不变
- 新节点内容区保持底部圆角（既有约定）
