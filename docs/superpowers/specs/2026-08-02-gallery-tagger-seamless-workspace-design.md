# 图库与标注无框一体化工作台设计

## 目标

将图库和标注从“独立工具嵌入主程序”的视觉状态，改造成与仪表盘共用同一窗口画布的两个专业工作区。页面继续保持各自独立的任务结构，只通过现有数据交接产生联动，不合并成同一个页面。

本轮同时删除侧栏顶部重复的品牌入口。窗口标题栏继续显示 Baka TOOLS，侧栏不再重复显示字母图标和产品名称。

## 已确认方向

采用“无框一体化工作台”，不采用多个悬浮卡片岛或单列极简画布：

- 删除图库和标注最外层的大边框、大圆角容器与独立底色。
- 保留对效率有帮助的分栏，但使用留白、低对比色阶和局部环境光表达区域关系。
- 只在控件、选中项、弹窗、错误提示和需要操作反馈的元素上保留明确边界。
- 页面标题退化为紧凑的上下文信息，不再占据一块独立标题区。
- 主页人物与横幅不复制到图库或标注；人物仍只出现在仪表盘。

## 共用视觉规则

### 连续画布

标题栏、侧栏、页面背景和状态栏使用连续的应用底色。图库与标注根节点透明，不再绘制第二层“应用窗口”。主内容在标题栏下直接展开，页面四周只保留 14–20 像素安全留白。

功能区域之间按以下优先级分隔：

1. 12–16 像素留白；
2. 轻微的背景明度差；
3. 必要时使用短分隔或局部分隔；
4. 不使用贯穿整个页面的硬横线、硬竖线。

### 表面层级

- 主画布：应用底色，承载图库网格或标注预览。
- 辅助区：比主画布略亮或略暖的透明色阶，不使用完整外框。
- 浮层：元数据、设置、拖入反馈和确认对话框可使用圆角、阴影与描边。
- 交互控件：按钮、筛选器、搜索框和选中项保留可识别的控件表面。

页面不新增装饰性玻璃框，不使用每一块内容都包一层卡片的结构。

### 动态反馈

- 导航、工具按钮和图片项目保留轻微位移、亮度或缩放反馈。
- 工作区本身不整体放大，避免密集操作时晃动。
- 拖入文件时使用覆盖当前内容画布的柔和蒙层，而不是在页面中央再弹出一个框。
- `prefers-reduced-motion: reduce` 下取消位移和缩放，只保留颜色变化与焦点轮廓。

## 侧栏改造

删除 `sidebar-brand` 品牌按钮、字母标记和产品名称。侧栏导航从标题栏下方自然开始：

- 宽侧栏顶部保留约 14–18 像素呼吸空间。
- 窄侧栏保持图标轨道，不为被删除的品牌区预留空白高度。
- 活动指示轨道从第一项导航重新计算起点。
- 底部本地模式和版本信息保持不变。
- 主页仍可通过“主页”导航项进入，不再提供第二个首页入口。

## 图库工作区

### 空间结构

图库保留“来源栏 + 内容画布 + 按需检查器”的结构：

- 来源栏宽度保持紧凑，直接融入页面背景；不再像嵌套侧栏一样画完整右边线。
- 顶部工具带与内容画布同宽，使用低对比度控件组合，不绘制贯穿全宽的底部横线。
- 图片网格直接占据剩余主画布；空状态位于画布视觉中心。
- 右侧检查器只在需要时出现，以浮出或色阶变化表达层级，不为关闭状态预留明显空壳。
- 批量选择工具保持贴近网格底部或选中内容，不形成第三条固定横栏。

### 信息层级

工具带从左到右保持：当前来源与数量、搜索、状态筛选、排序、视图切换、同步和添加。按钮权重分为三档：

- “添加文件夹”是主要操作；
- 同步和视图切换是次要操作；
- 状态、排序和搜索使用安静控件。

图库没有图片时，空状态只显示一句说明和一个主要入口，不重复左侧来源栏已有的多个入口。

### 现有能力保持

拖拽读取、文件夹同步、数据集、批量选择、双击元数据、发送到标注、发送到训练、复制与移动文件等行为全部保持不变。本轮只调整呈现结构和视觉层级。

## 标注工作区

### 空间结构

标注继续保持“任务队列 + 图片预览 + 标签校对”三段式工作流，但取消包住三栏的 `tagger-shell` 外框：

- 顶部变为一条紧凑控制带，展示当前进度、模型和主要操作。
- 中央图片预览是最大、最深的视觉区域，占据主要宽度。
- 左侧队列比现在更轻、更窄，使用选中态和行间距组织任务，不依赖完整边框。
- 右侧标签校对使用略亮的辅助表面，与预览区保持 12–14 像素呼吸间距。
- 三个区域各自滚动，页面本身不产生多余双重滚动。
- 底部模型、阈值和设备摘要并入预览区下方的轻量状态带，不绘制全宽硬横线。

### 空状态与运行状态

- 空队列时，主要引导集中在图片预览区；左侧只保留简短队列说明，避免三个区域同时显示三套空状态文案。
- 运行时进度替换轻量状态带，不额外撑开页面高度。
- 失败信息在进度区域使用明确的错误色阶，但不恢复完整边框外壳。
- 停止、保存、上一张、下一张和模型设置的现有行为保持不变。

## 图库与标注联动

两个工作区继续独立：图库只向标注传递图片队列和返回上下文；标注不直接操纵图库页面布局。标注完成后继续通过现有存储与保存逻辑回写 caption 和标签。

视觉上使用相同的控件圆角、间距、色阶、焦点轮廓和状态颜色，使跳转看起来是在同一个应用中切换工作阶段，而不是打开另一个嵌入工具。

## 响应式规则

- 1200 像素以下：应用侧栏切换为图标轨道；图库来源栏缩窄；标注队列缩窄。
- 980 像素以下：图库检查器以覆盖层出现；标注标签校对区允许折叠或覆盖，不压缩中央图片到不可用尺寸。
- 760 像素以下：优先保证主要画布和操作按钮，辅助区使用现有收起入口；不得产生页面级横向滚动。
- 低高度窗口压缩工具带和状态带，不压缩图片预览与关键按钮的可点击高度。

## 可访问性与容错

- 删除品牌首页按钮后，“主页”导航项仍具有清晰名称和键盘焦点。
- 所有图标按钮继续提供可访问名称或 `title`。
- 不以颜色作为唯一的选中、错误或运行状态提示。
- 收起辅助区后，键盘焦点不能停留在不可见内容中。
- 页面数据加载失败时复用现有错误提示，不以空白画布掩盖错误。
- 视觉改造不得改变拖入、元数据、标注保存和训练交接的 IPC 调用。

## 验收标准

### 自动验证

- 侧栏模板不再包含 `sidebar-brand`、`brand-mark` 或 `brand-name`。
- 侧栏活动轨道在宽侧栏和图标轨道模式下均与第一项导航对齐。
- 图库根工作区和标注三栏容器没有完整边框或独立外壳阴影。
- 图库现有拖拽、双击元数据、数据集交接与批量操作测试继续通过。
- 标注队列、自动标注、保存、停止与图库返回上下文测试继续通过。
- 减少动态效果、类型检查、IPC 契约检查和渲染构建通过。

### 真实窗口验收

- 1400×900：图库和标注看起来与窗口是一个整体，不存在明显“页面套页面”。
- 1100×720：侧栏为图标轨道，图库和标注无横向溢出，主要按钮不被裁切。
- 图库网格为空和有图两种状态均保持清晰；拖入蒙层覆盖内容画布而不是整个应用。
- 标注空队列只保留一个主要引导；有任务时中央图片明显成为视觉主体。
- 从图库进入标注时，控件语言、留白和表面层级连续。

## 不在本轮范围

- 不合并图库和标注路由。
- 不改变图库、标注、反推或训练的数据模型。
- 不更换人物、横幅、品牌色或图标库。
- 不重新设计元数据弹窗内部信息结构。
- 不修改训练器页面。
- 不发布、不上传、不生成安装包。
