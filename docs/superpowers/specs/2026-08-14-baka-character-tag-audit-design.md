# 角色标签审计设计

## 目标

为 Baka TOOLS 增加接近 BDTM 的角色标签审计能力：

1. 从当前数据集生成角色标签清单。
2. 结合触发词、标准图和 LLM 做两阶段审计。
3. 对每个角色标签给出保留、删除、替换、不确定。
4. 支持多角色数据集。
5. 检查父子标签冲突和人数标签冲突。
6. 用户确认后事务化写入。

## 范围

本轮实现：

- 单角色审计。
- 多角色审计，最多 4 个角色。
- 文本初筛 + 视觉复核。
- 逐条人工复核和批量应用。
- 父子标签合并。
- 人数标签冲突修复。
- 审计报告。

本轮不做：

- 自动下载角色数据。
- 云端角色百科。

## 流程

```text
用户设置触发词和标准图
  -> 扫描数据集标签
  -> 生成角色标签清单
  -> LLM 文本初筛
  -> LLM 视觉复核
  -> 用户逐条复核
  -> 批量应用
  -> 事务化安全写入
```

## 模块

### `electron/ipc/character-tag-audit.js`

负责：

- 扫描数据集。
- 生成清单。
- 调用 LLM。
- 生成审计结果。
- 应用决策。

### `electron/ipc/character-tag-decisions.js`

负责：

- 决策类型。
- 父子标签规则。
- 人数标签规则。
- 合并建议。

### 前端

- `CharacterTagAuditDialog.vue`
- `CharacterTagAuditReview.vue`

## 决策类型

- keep：保留。
- delete：删除。
- replace：替换。
- unsure：不确定。

## 人数标签修复

- `1girl` / `2girls` 冲突时，保留人数最多的标签。
- 多人图中删除 `solo`。

## 父子标签处理

- 使用内置角色关系表。
- 同一家族多个标签同时出现时，建议保留父标签。
- 子标签出现次数低时，建议合并到父标签。

## 安全写入

审计应用使用 `safe-file.js` 和事务化写入，单张失败不中断整批。

## 测试

- 标签清单生成。
- 决策应用。
- 人数冲突修复。
- 父子合并。
- 多角色归属。

## 验收标准

1. 能生成角色标签清单。
2. 能进行文本初筛和视觉复核。
3. 决策正确应用。
4. 人数冲突可修复。
5. 父子标签可合并。
6. 写入失败不破坏原文件。
7. 相关测试通过。
