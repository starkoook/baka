# Baka TOOLS 在线组件管理设计

日期：2026-07-28
状态：待用户书面确认后实施

## 目标

Baka TOOLS 改为轻量安装。图库、标注、反推等功能安装后立即可用；只有用户第一次进入训练器并确认安装时，才下载训练器核心和与显卡匹配的独立运行环境。

当前阶段不公开发布、不连接正式 GitHub Releases，使用本地测试源完整模拟检查、下载、校验、安装、修复、升级和回退。未来发布时只替换组件源配置，不修改业务界面和安装流程。

## 不做的事情

- 不把 Python、PyTorch 或训练环境塞进默认 Setup。
- 不把 3–8 GB 的固定离线包作为主要交付物。
- 不自动下载 SD1.5、SDXL、Flux 等基础模型。
- 不在本阶段上传 GitHub Releases、推送公开更新或购买代码签名。
- 不让训练组件故障影响图库、标注和反推。

## 用户体验

1. 用户安装轻量版 Baka TOOLS。
2. 用户打开图库、标注或反推时，无须安装训练组件。
3. 用户第一次进入训练器时，Baka 检测 NVIDIA、AMD 或 Intel 显卡。
4. 页面显示推荐环境、预计下载量、预计占用空间、下载来源和安装位置。
5. 用户点击一次“安装训练环境”，系统依次安装训练器核心、portable Python、PyTorch 和训练依赖。
6. 下载支持暂停取消、断点续传、失败重试和 SHA-256 校验。
7. 安装完成后自动进行健康检查，通过后才能启动训练器。
8. 后续升级只下载发生变化的组件；PyTorch 未变化时不重复下载。

## 方案选择

采用“轻量 Setup + 在线组件管理器 + 可导入导出的本地缓存”。

不采用以下方案：

- Setup 内置训练器核心：安装包仍会随上游核心增长，核心更新也必须重打 Baka 安装包。
- 完整离线包：体积过大，显卡环境不同会造成大量无用文件。
- 直接 `git clone` 最新代码：版本不可复现，上游变化可能导致已经发布的 Baka 突然失效。

## 组件结构

组件分为四类，并分别记录版本：

| 组件 | 内容 | 更新方式 |
|---|---|---|
| Baka | Electron 主程序、图库、标注、反推、下载器 | 独立更新 |
| trainer | 固定版本训练器核心压缩包 | 按需下载与回退 |
| schema | 训练 Schema、预设和工具清单版本 | 随 trainer 校验，可单独记录 |
| runtime | portable Python、PyTorch、训练依赖 | 按显卡类型安装 |

训练器核心使用固定版本压缩包，不拉取未经锁定的仓库默认分支。每个组件必须在清单中提供版本、大小、SHA-256、兼容范围和相对下载地址。

## 组件清单

本地测试源和未来 GitHub Releases 使用同一份 `manifest.json` 格式：

```json
{
  "formatVersion": 1,
  "channel": "stable",
  "components": {
    "trainer": {
      "version": "v1.6.2",
      "file": "trainer-v1.6.2.zip",
      "size": 112000000,
      "sha256": "...",
      "minimumBaka": "0.2.0"
    },
    "runtime-standard": {
      "version": "torch2.10-cu128-v1",
      "file": "runtime-standard.zip",
      "size": 5600000000,
      "sha256": "...",
      "trainerRange": ">=v1.6.2 <v2.0.0"
    }
  }
}
```

当前默认读取用户选择的本地测试源目录。开发人员可以用构建脚本生成测试清单和组件包。未来发布只新增 HTTPS/GitHub Releases 源适配器。

## 下载与安装状态

单个组件采用以下状态：

```text
未安装 → 检查空间 → 下载中 → 校验中 → 解压中 → 健康检查 → 可用
                  ↘ 已暂停 / 已取消 / 下载失败
                              ↘ 校验失败 / 安装损坏 → 修复
```

- 下载先写入 `.part` 文件，保留已下载字节数和 ETag/源文件信息。
- 恢复时验证源没有变化，再使用 Range 请求继续。
- 校验失败不覆盖当前可用版本。
- 解压到临时目录，健康检查通过后再原子切换 `active.json`。
- 保留上一个可用 trainer/runtime，支持一键回退。
- 训练、环境安装或组件切换期间互斥，不能同时执行。

## 目录结构

```text
用户数据目录/
  component-manifest.json
  trainer/
    active.json
    versions/v1.6.2/
  runtimes/
    active.json
    standard/torch2.10-cu128-v1/
  downloads/
    *.part
    state.json
  cache/
    packages/
  models/                 用户自行管理或选择外部目录
```

训练器核心、运行环境、下载缓存和用户模型互不混放。删除训练环境不会删除模型、图库或 caption。

## 显卡推荐

推荐结果继续由训练器的 runtime coordinator 提供，不在 Baka 前端重复维护判断规则。

- NVIDIA 常规显卡：standard。
- NVIDIA 特定新架构：按兼容清单推荐 Blackwell 等环境。
- AMD：ROCm 环境。
- Intel：XPU 环境。
- 未识别显卡：不自动猜测，显示通用说明并允许用户查看兼容环境。

推荐只是默认选择。真正安装前还要检查驱动、磁盘空间和组件兼容范围。

## 缓存导入与导出

不再维护一个固定巨型离线包，改为可携带缓存：

- 下载完成后可“导出训练环境缓存”。
- 另一台电脑可“导入本地缓存”，校验通过后直接安装。
- 缓存包只包含用户选择的 trainer/runtime，不包含模型和图库数据。
- 导入缓存和在线下载使用同一清单与 SHA-256 校验流程。
- 缓存不兼容当前 Baka 或显卡时禁止安装，并说明原因。

## 下载源

组件管理器使用统一源接口：

1. 本地测试源：当前阶段默认，用于模拟完整发布流程。
2. 官方 HTTPS/GitHub Releases：未来发布时启用。
3. 镜像源：为国内网络预留，不在本阶段绑定具体服务。
4. 自定义源：高级用户可填写地址，但必须通过同一清单校验。

源切换只影响下载位置，不能绕过版本兼容和 SHA-256。

## 安全与许可证

- 不执行清单之外的任意脚本。
- 所有组件在解压前校验 SHA-256。
- 防止 ZIP 路径穿越，禁止解压到组件目录之外。
- 清单格式和兼容字段严格验证，未知字段给出提示。
- 训练器核心继续附带 AGPL-3.0、第三方组件清单和源代码地址。
- 下载日志不记录代理密码、令牌或用户模型路径中的敏感信息。

## 界面调整

训练器未安装时显示一个安装引导卡片：推荐环境、下载大小、占用空间、安装位置、源和“开始安装”。

安装期间显示当前组件、总进度、已下载/总量、速度、剩余时间，以及暂停、继续、取消按钮。失败时显示“继续下载”“重新校验”“修复环境”，不展示无法理解的堆栈信息。

设置页增加“训练组件”区域，可查看版本、检查更新、回退、修复、清理下载缓存、导出缓存和导入缓存。

## 现有实现迁移

- 从默认 Setup 的 `extraResources/trainer-core` 中移除训练器核心。
- 正式版不再通过内置核心初始化训练器。
- 保留开发模式的本地参考目录，仅用于调试和构建测试组件。
- 当前生成的 3.8 GB 离线 ZIP 不再作为交付物；确认新流程通过后删除生成文件。
- 已安装的用户数据目录中的 trainer/runtime 继续识别，不强制重新下载。
- 当前版本回退、Schema 动态表单、图库联动、训练监控和 LoRA 工具功能保持不变。

## 错误处理

- 无网络：保留进度，提示可重试或导入缓存。
- 空间不足：下载前阻止，并显示还差多少空间。
- 下载中断：保留 `.part` 和断点信息。
- SHA-256 失败：隔离坏文件，不覆盖可用版本。
- 解压失败：删除本次临时目录，保留旧版本。
- 环境损坏：先健康检查，再按缺失组件修复；无法修复时重新安装该 runtime。
- 正在训练：禁止升级、回退、修复和清理活动环境。

## 验收标准

- 默认 Setup 中不包含 trainer-core、Python 或 PyTorch。
- 未进入训练器时不产生训练组件目录和网络请求。
- 本地测试源可完整模拟检查、断点下载、校验、安装、启动、升级和回退。
- NVIDIA、AMD、Intel 推荐由 runtime coordinator 返回。
- 中断下载后可以续传，已完成组件不重复下载。
- 校验失败、空间不足和损坏环境不会破坏上一可用版本。
- 可导出一个环境缓存并在另一测试目录导入安装。
- 图库、标注、反推在没有训练组件时正常运行。
- 最终生成轻量 `Baka-TOOLS-Setup.exe`，不上传、不公开发布。
