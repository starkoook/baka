# 图库统一导入与完整元数据设计

## 目标

图库只保留一个明确的“导入”入口。用户可从该入口选择图片或选择文件夹；选择图片时使用系统图片选择器，因此能在确认前看到文件名和缩略图。图片进入图库时立即解析生成元数据，已导入图片在下一次同步时自动补齐新版解析结果。

## 导入交互

- 工具栏保留一个“导入”按钮，展开后提供“选择图片”和“选择文件夹”。
- 删除来源栏标题旁和来源栏底部的两个重复添加按钮。
- “选择图片”允许多选，确认后直接进入图库并刷新列表。
- “选择文件夹”继续注册图库根目录并递归同步。
- 拖入单张图片仍用于临时查看元数据；拖入多张图片或文件夹仍按现有规则导入。

## 元数据读取

- 保留 PNG 文本块中的原始键值，例如 `prompt`、`workflow`、`parameters` 和自定义字段。
- 继续规范化 ComfyUI、A1111/WebUI、Forge、NovelAI 的常见字段：提示词、反向提示词、模型、尺寸、种子、步数、CFG、采样器、VAE、CLIP 和工作流节点信息。
- ComfyUI LoRA 同时识别标准 `LoraLoader` 节点和自定义节点中的 `lora_str` JSON。
- `lora_str` 只显示 `hidden !== true` 的当前 LoRA；`temp_lora_str` 作为原始元数据保留，但不计入当前生效 LoRA。
- LoRA 按名称和权重去重，保留模型权重与文本编码器权重。
- 无法规范化的元数据仍保存在“原始元数据”中，不能在导入时丢弃。

## 缓存与旧图片升级

数据库新增完整元数据 JSON 缓存字段，同时保留现有快速查询字段以兼容旧代码。新版第一次同步时，缓存字段为空的旧图片即使文件时间未变化也会重新解析；之后恢复按修改时间跳过未变化文件。

图库查看器增加“原始数据”页，显示并允许复制完整原始元数据。概览页将每个生效 LoRA 单独显示名称、模型权重和文本编码器权重，避免把临时列表误当作本次生成参数。

## 验收

- 样例 `ComfyUI_temp_zcgha_00011_.png` 解析出 7 个当前 LoRA，不包含 `temp_lora_str` 中的 8 个历史条目。
- 样例的 `prompt` 与 `workflow` 原始文本都被保存。
- 图库普通界面只出现一个导入按钮，菜单中有图片和文件夹两个入口。
- 旧图库图片同步一次后得到完整元数据缓存，无须重新导入。
- 现有拖拽、扫描、元数据查看与标注交接测试继续通过。
