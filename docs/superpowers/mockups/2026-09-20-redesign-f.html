06与现在的区别 · 保留了什么

保留

  • 工具选择页：全屏海报随悬停切换、底部卡片悬停抬起 12%、拖动横向滚动、自定义海报（设置里换图）全部保留。
  • 侧栏的"回到上一个工具"圆形海报按钮，升级为常驻的"当前工具"头像。
  • 标注页底部胶囊操作坞、图库的搜索语法、回收站、安全移动。
  • 点击音效（nya）和深浅主题切换（深色版另出一稿）。

改掉

  • 紫黑"编辑风"外壳 → 粉紫渐变底 + 白卡片 + 粉柔影。
  • 首页 620 px 呼吸大图 → 312 px 静态封面卡，插画从右侧柔和渐入。
  • 工具选择里写死的 1,284 / 36 / E03 → 真实数字；4 个工具共用一张海报 → 每个工具一张。
  • 模糊光晕、滚动视差、3D 透视全部去掉；卡片投影统一为粉色柔影。
  • 在线画廊、标注、训练各自一套样式 → 同一套控件（05）。

下一步

  • 你点头后：先做外壳（窄栏 + 顶栏 + 工具选择换皮）和首页，出安装包给你实机看。
  • 再做图库三栏 + 缩略图走 media:// + 只渲染可见区域。
  • 然后标注、训练、在线画廊逐页套用 05 的控件。
  • 深色版：同一结构，底色换成深梅子紫，粉色主色不变，工具选择页本来就是深的不用改。
