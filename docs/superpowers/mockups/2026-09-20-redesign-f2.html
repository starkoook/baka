04说明

和上一版比

  • 侧栏从"一整条"变成一颗浮着的胶囊；顶栏拆成几粒药丸，画面四周留出呼吸感。
  • 四个一样大的数字卡 → 一个圆环大卡 + 两张歪着的小卡 + 三张贴纸。
  • 六张整齐缩略图 → 一叠拍立得；系统条形图 → 三个甜甜圈；再加一句小人气泡。
  • 图库：工具栏悬浮、网格圆角加大、悬停放大微倾、详情预览像一张歪着别上去的照片、底部出现深色批量操作胶囊。
  • 标注：队列变成竖向胶片、图片是桌面上的一张照片、标签歪 1–2°、右上角小人探头。

不会影响流畅度

  • 倾斜、出框、贴纸都是静态 transform，没有渲染开销。
  • 动效只有三处：拍立得悬停立正、网格悬停放大、按钮按下回弹，全部 transform + opacity，≤ 250 ms。
  • 背景光斑是三张静态径向渐变，不做模糊动画；小星星是静态字符。
  • 系统开启"减弱动效"时全部关闭。

下一步

  • 你点头后按这版开始改真实程序：外壳 + 工具选择换皮 + 首页 → 出安装包实机看 → 图库 → 标注、训练、在线画廊。
  • 训练、在线画廊、工作台沿用同一套手法：悬浮胶囊工具栏、圆环进度、贴纸状态。
  • 深色版：底色换深梅子紫，贴纸和卡片变成半透明白，粉色不变。
