# Baka TOOLS 工具箱 · 长远规划（大白话版）

> 这份文档用最直白的话说明：工具箱要往哪里走、用什么技术、每阶段做完长什么样。你也可以照着最后一节的"描述模板"更准确地提需求。

## 一句话定位

**一个桌面版 AI 创作工作台**：把素材（图片/视频/文本）、AI 能力（生成/打标/改写）、处理工具（裁剪/缩放/切分）都摆在无限画布上，像搭积木一样搭出你的工作流，点一下"运行"就从头跑到尾。

## 技术栈（先认识这些词）

| 技术 | 是干什么的 | 在工具箱里管什么 |
|---|---|---|
| Vue 3 + TypeScript | 前端界面框架 | 所有页面、节点界面、设置面板 |
| Electron | 桌面外壳 | 把网页变成 Windows 程序，负责窗口、文件读写、系统能力 |
| 自研画布（DOM + SVG + Canvas） | 画布引擎 | 节点、连线、框选、小地图 |
| HTML5 Canvas | 浏览器级图片处理 | 本地工具：裁剪/缩放/宫格/旋转 |
| 通用 AI 适配层 | AI 接入 | 按你选的配置调 OpenAI 兼容或 Gemini 的文本/打标/生图接口 |
| Node.js（Electron 主进程） | 后台能力 | 文件保存、凭据库、以后调本机模型 |
| JSON 本地文件 | 数据存储 | 画布工作流、设置、API 凭据（以后可升级 SQLite） |
| Vite / Vitest / electron-builder | 开发工具链 | 开发、测试、打包安装包 |

## 四个阶段

### 阶段 1：工作台地基（正在进行，大部分已完成）

- 无限画布：节点、连线、框选、小地图、撤销/重做、复制/粘贴/剪切 ✅
- 素材节点 + 内嵌生成器：图片/文本节点里直接选配置、选模型、写提示词、生成，自动派生新节点并连线 ✅
- 本地工具：裁剪、宫格切分、缩放、旋转 ✅
- AI 节点：AI 打标、LLM 文本 ✅
- API 凭据库：多套配置统一管理、获取可用模型、测试连接 ✅
- 运行体系：单节点运行 + 整组运行 + 节点状态（运行中/完成/出错） ✅
- 保存/下载：节点内容一键保存 ✅
- 右键灵活性：输入框里用系统原生菜单，节点/画布右键有复制/剪切/粘贴 ✅
- 待收尾：**工作流保存/打开**（画布存成文件）、视频节点生成器、AI 工具与真实生图服务联调

### 阶段 2：让工作流真正干活

- 工作流保存 / 打开 / 分享：整张画布存成一个文件，随时恢复
- 批量运行 + 队列 + 进度条：一次跑一批图/文本
- AI 工具完善：高清放大、扩图、重绘（取决于你接的生图 API 能力）
- 视频节点：内嵌视频生成（视频模型 API）、剪辑、合成
- 模板库：把常用流程存成模板，一键复用（LibTV 的"打组 + 工作流模板"）

### 阶段 3：开放与插件

- 节点市场：从 GitHub 导入节点（已有雏形），支持"带代码的节点包"（像 ComfyUI 的自定义节点）
- 本地模型接入：连接 ComfyUI / 本地 Stable Diffusion 服务，不出网也能生图
- 脚本节点：自定义动作（调用任意 API、跑本地命令）
- 主题与布局自定义

### 阶段 4：成片与协作

- 一键成片：脚本节点 → 批量分镜 → 视频生成 → 合成 → 导出（LibTV 式）
- 画布分享 / 发布：把工作流发给别人用
- 安装包自动更新
- Agent 接口：让 AI 助手能直接操作画布（自动搭流程）

## 怎么算一个阶段做完

- 阶段 1：打开就能搭流程、保存、运行、导出，用户不需要看文档
- 阶段 2：复杂任务（比如"一套图出三张变体再切分"）能在画布里一条龙完成
- 阶段 3：不写代码也能装第三方节点和接本地模型
- 阶段 4：一句话生成一部短片，画布可分享、可自动更新

## 提需求的"描述模板"

以后提需求可以套这个格式，我能更快理解：

> 在【哪里：哪个页面 / 哪个节点 / 右键 / 工具栏】…… 我希望【什么行为：点一下 / 拖一下 / 自动发生】…… 像【哪个工具：ComfyUI / LibTV / n8n】那样…… 因为【想解决什么问题】。

示例：

- "在图片节点里，点工具条的高清放大，我希望先弹一个 2×/4× 的选择，再开始跑，像 ComfyUI 的放大节点那样，因为我想要更可控。"
- "在画布空白处右键，我希望菜单里除了添加节点还有'粘贴'，而且粘贴到我右键的位置，像 Figma 那样。"
- "运行整组的时候，我希望底部有一个进度条显示当前跑到第几个节点，像 n8n 那样，因为流程长了不知道卡在哪。"
