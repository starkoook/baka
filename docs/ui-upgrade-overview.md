# Baka TOOLS — 画面效果升级（UI Designer 交付说明）

> 说明：本项目是 Vue + Electron 桌面工具箱（处理动漫图片），**不是虚幻引擎项目**，所以没有游戏级的 3D 技术美术/着色器那一说。以下是以 **UI 设计师** 视角，对现有"赛博 HUD + 可爱"皮肤做的 **提质 + 提效** 一轮优化。

## 做了什么

### 1. 背景光效提质（技术美术向）
- 环境光晕从「平涂径向渐变」→ 柔和「体散光池」：`blur(48px)` + `mix-blend-mode: screen`，更有光的体积感。
- 樱花数量 24 → 14，呼吸感不变，但更省 GPU。

### 2. 画面不吃性能
- 为背景层（光晕 / 噪点 / 樱花）加 `will-change` + `translateZ(0)`，提升到独立合成层，动画走 GPU 而非触发布局/重绘。原来那套常驻渲染，窗口在后台也烧显卡。
- 新增 `prefers-reduced-motion` 支持：系统开启「减弱动效」时自动停用樱花 / 光晕 / 噪点（照顾晕动症用户）。

### 3. 对比度达标（无障碍 WCAG AA）
- 深 / 浅主题的三级、四级灰字，从约 3:1 提到约 5:1，小字也看得清。

### 4. 描边统一主题化
- 卡片角落刻度、规格字等写死的粉色 `rgba(244,114,182,...)` 全部换成 `rgba(var(--accent-primary-rgb),...)`，深浅色现在都跟手，不再"露馅"。

### 5. 新增设计令牌
- 4px 基准间距 scale（`--space-*`）、分层柔和阴影 ramp（`--elev-1/2/3`、`--elev-glow`）、体光 token（`--glow-pink/orange`）。

### 6. 把你的 Live2D / 2D 小人请回来了（第二轮补做）
- 真实工程里小人一直在：`Dashboard.vue` 的 `.holo-pod` 里渲染 `<Mascot />`（基于 `/mascot.png` 的 2D 小人，含 idle/walk/sit/sleep/bounce 状态机、鼠标视差、点击爱心），受 `appStore.showMascot` 控制，默认显示。可选的 `Live2DLoader.vue`（pixi.js 版）是另一套独立组件，需要装依赖 + 放模型文件。
- 上一轮预览页只是简化 mock，**没画小人**，所以你双击预览时以为丢了对吧——其实没丢，是预览漏了。本轮在 `ui-upgrade-preview.html` 里补了一个 **全息座 + 小人**：透视网格地面、脉动地光、旋转光环，小人用内联 SVG 画（独立文件里没有 `/mascot.png` 资源，所以用矢量小人占位，真机里跑的就是你那张图）。

### 7. 补回"感觉"（视觉冲击力 / 灵魂感）
- **中央主光池** `.core-glow`：双色 screen 混合径向光，9s 呼吸缩放，画面中心更有"活气"。
- **景深视差**：鼠标移动时背景网格 / 光晕以不同速率反向位移，小人跟着转头看过来（rotateX/Y），空间感一下就出来了。可一键关。
- **扫描线 + 暗角**：HUD 氛围叠层，赛博质感拉满（对比旧版时自动隐藏）。
- **漂浮微光粒子** `.sparkles`：✦ 缓慢上浮，画面不再"死"。
- **小人微交互**：鼠标悬停转头、点击蹦爱心 + 气泡（"呀！/别戳~"），还会自己偶尔冒一句"主人回来啦？"，真的像在陪你。
- 卡片 hover 加了掠过的高光扫光。

## 第三轮：把"灵魂感"从预览页端口进真机
- 预览页那套增强效果（主光池、扫描线、暗角、粒子、视差）原本只在 mock 里，真实 Vue 工程没吃到。本轮端口进 `MainLayout.vue` + `global.css`：
  - **主光池 `.core-glow`**：双色 screen 混合径向光，9s 呼吸缩放。
  - **HUD 氛围**：`.scanlines` 扫描线 + `.vignette` 暗角叠层。
  - **漂浮粒子 `.sparkles`**：10 个 ✦ 缓慢上浮（脚本生成，非写死）。
  - **鼠标视差**：`onMove` 监听鼠标，给 `.main-layout` 设 `--px/--py`，光晕层与主光池反向位移，空间感更足；减弱动效时自动停用。
  - 全部 `pointer-events:none`、独立合成层、`prefers-reduced-motion` 下整体隐藏，性能与无障碍不受影响。
- 真机小人的鼠标转头 / 点击爱心 / 状态机本来就在 `Mascot.vue`（受 `showMascot` 控制），无需改动。

## 怎么看效果
- **真机**：`npm run dev` 启动 Electron，背景会有主光池呼吸 + 扫描线 + 暗角 + 漂浮粒子，鼠标移动时背景轻微视差；左下角（Dashboard）是真实 `/mascot.png` 小人，会转头、点击蹦爱心。
- **预览页**：直接双击 `ui-upgrade-preview.html`，右下角控制坞可切换 **新版光效 / 小人出战 / 樱花飘落 / 景深视差 / 减弱动效 / 浅色模式**；关「新版光效」对比旧版平涂硬边背景。
