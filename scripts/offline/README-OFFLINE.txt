Baka TOOLS NVIDIA Standard 离线包

推荐安装：
1. 完整解压 ZIP，不要直接在压缩软件里运行。
2. 双击 offline-installer\Install-Baka-Offline.cmd。
3. 完成 Baka TOOLS 安装向导后，脚本会自动把训练器和 NVIDIA standard 环境复制到当前用户目录。
4. 打开 Baka TOOLS，进入“训练器”。

如果 Baka TOOLS 已安装，可只运行：
offline-installer\Install-Offline-Environment.ps1

离线环境版本和 SHA-256 见 ZIP 外的 offline-version-manifest.json 与 .sha256 文件。
